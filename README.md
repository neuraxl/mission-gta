# Mission GTA — L'Empire des émotions

**Ta pub devient un jeu.**

Site statique (100 % autonome) : `index.html` à la racine.

Les visiteurs y créent une publicité style GTA à partir de leur photo : l'intelligence artificielle écrit le scénario, le rendu est affiché sur la page pendant **15 minutes maximum**, puis il disparaît. Les créations sont conservées dans le dossier séparé [`creations/`](creations/).

- Version gratuite : capsule de 10 secondes
- Créateur Pro : 14,99 $/mois
- Studio Empire : 39,99 $/mois

Une production Sav'art — Roger Savard, auteur, compositeur, producteur.
