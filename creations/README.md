# Dossier des créations — Mission GTA

Chaque création produite par le studio Mission GTA est archivée ici, dans ce dossier séparé du site GitHub, **une création par mission**.

## Le principe

- Le rendu d'une création reste affiché sur la page du site pendant **15 minutes maximum** (compte à rebours visible), puis il disparaît automatiquement de la page.
- Disparu de la page ne veut pas dire perdu : la création est conservée ici, dans `creations/`.
- Chaque mission a son propre sous-dossier, nommé selon la date et le commerce :

  `creations/AAAA-MM-JJ_<nom-du-commerce>/`

## Exemple archivé

- [`2026-11-23_depanneur-du-coin/`](2026-11-23_depanneur-du-coin/) — première mission archivée, le 23 novembre 2026.
